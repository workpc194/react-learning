# React Learning

A collection of small projects and experiments I built while learning React.  
Each project focuses on a specific concept or feature so I can practice and understand React step by step.

---

## 📌 About This Repository

This repository contains multiple mini projects created during my React learning journey.  
The goal is to practice core React concepts through real, hands-on examples instead of just theory.

Most projects are built with:

- **React 19**
- **Vite**
- **Tailwind CSS**

---

## 🧩 Projects Included

### 📝 Notes App
A simple notes application where you can create notes with a title and details.  
Built using `useState` for state management and Tailwind CSS for styling.  
Notes are displayed as cards in a clean dark-themed UI.

**Live Demo:** [notes-app-by-noman.vercel.app](https://notes-app-by-noman.vercel.app/)

---

### 🖼️ Gallery Project
An infinite-scrolling image gallery that fetches photos from the Picsum Photos API.  
Features include infinite scroll, Axios for API calls, and a reusable Card component.  
Images are displayed in a responsive flex-wrap layout with author names.

**Live Demo:** [gallery-app-by-noman.vercel.app](https://gallery-app-by-noman.vercel.app/)

---

### 🔢 Counter App
A basic counter application to practice fundamental React concepts like state updates and event handling.

---

### 🎨 Tailwind CSS
Practice project focused on learning and applying Tailwind CSS utility classes with React + Vite.

---

### 🔄 Context API
Project dedicated to learning React Context API for sharing state across components without prop drilling.

---

### 🌐 API Learning
Practice project focused on making API calls, handling responses, and working with external data in React.

---

### 🛣️ React Routing
A storefront-style demo built to learn React Router and client-side navigation.

---

### ⚛️ React Pro
Additional React practice and experiments.

---

## 🎯 What I Learned

Through these projects I practiced:

- React fundamentals (components, JSX, props, state)
- `useState` and controlled form inputs
- Fetching data from APIs with Axios
- Infinite scrolling
- React Context API
- React Router
- Building reusable components
- Styling with Tailwind CSS
- Working with Vite
- Deploying React apps (Vercel)
